# G検定ドリル

G検定（JDLA Deep Learning for GENERAL）対策の学習用Webアプリです。
HTML / CSS / JavaScript のみで動作し、ビルド不要で GitHub Pages に公開できます。

## 機能

- **分野別演習**：シラバスに沿った10分野から出題。1問ごとに正誤と解説を表示
- **おまかせ演習・苦手復習**：未回答・前回不正解の問題を優先して出題
- **模擬試験**：制限時間つき（本試験の目安 100分・約145問から換算）。見直しの印、問題一覧、分野別の採点結果
- **用語集**：検索できる一覧と、めくって覚えるフラッシュカード
- **学習記録**：分野別の習得率、直近14日の解答数、模擬試験の履歴、JSONでのエクスポート / インポート
- ダークモード、スマートフォン表示、キーボード操作（A〜D / 1〜4 で解答、Enter で次へ）に対応

学習記録はブラウザの localStorage にのみ保存され、外部には送信されません。

## ローカルで開く

`index.html` をブラウザで直接開くだけで動作します。

## GitHub Pages で公開する

1. このリポジトリを GitHub に push する
2. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする
3. `main` ブランチへの push のたびに `.github/workflows/pages.yml` が自動でデプロイする

Actions を使わない場合は、Source を **Deploy from a branch**（`main` / `/ (root)`）にしても公開できます。

## 問題・用語の追加

| ファイル | 内容 |
| --- | --- |
| `js/data/questions.js` | 問題。`a[0]` が正解（表示時に選択肢はシャッフルされる） |
| `js/data/glossary.js` | 用語集 |
| `js/data/categories.js` | 分野の定義 |

問題IDは「分野ID-分野内の通し番号」で自動採番されます。既存の学習記録とずれないよう、問題は**各分野の末尾に追加**してください。

```js
{ c: "ml", q: "問題文", a: ["正解", "誤答1", "誤答2", "誤答3"], e: "解説" },
```

## 注意

- 問題は公式の過去問ではなく、シラバスの範囲をもとに作成したオリジナル問題です。法令やガイドラインは改正されることがあるため、最新の情報は公式資料で確認してください。
- これはCloude Codeを用いて作成されました。
